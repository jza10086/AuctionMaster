# 竞拍大师

1–8 人密封竞拍，支持单人测试。左侧最多八张玩家卡片显示姓名、最近一次已公开报价，以及本仓已结束轮次的辅助操作圆角正方形色块；尚无公开报价时显示横线。中央滚动仓库显示本人已发现的物资，右侧提供可编辑报价输入框、增减报价和辅助色块按钮，悬停或聚焦时在按钮下方说明操作内容。顶部左侧显示本人剩余金币，居中显示带边框的数字倒计时（剩余 10 秒及以下变红），右侧显示轮数。归零与确认报价按钮在右侧底部垂直排列，所有操作按钮使用项目通用边框，金额统一使用千位分隔符；不显示日志、标题说明或角落提示。

默认一局 3 个仓库，每仓最多 5 轮，每轮 15 秒，所有玩家初始 80,000 金币。房间设置可修改仓库数（1–10）、每仓最多轮数（1–5）、竞价时间、揭示时间、成交结算时间、统一初始金币、每仓物品数量范围（默认 20–40，允许 1–100）和七档品质权重。数量下限不能大于上限；品质权重不能全部为 0。

- 报价可手动输入，也可使用 ±100 / 500 / 1,000 / 5,000 / 10,000 和归零按钮；输入支持千位分隔符，失焦或回车后格式化。非整数、非 100 整数倍或超余额的输入标红并禁止确认。所有有效报价都是 100 的整数倍，不能超过余额；0 或超时为本轮放弃。各轮报价独立，未成交不扣钱。
- 所有人确认后提前进入完整 3 秒封盘倒计时，期间不接受新报价或辅助操作；竞价时间自然耗尽则直接结束出价。结束后统一公开本轮报价和操作，进入默认 10 秒的揭示阶段（设置可调整为 1–60 秒），所有轮次包括成交轮均保留核对时间。之后未成交进入下一轮，成交或流拍进入开仓展示。出价及封盘期间，所有玩家的卡片只显示已完成轮次；本轮辅助类型不进入公开或其他玩家的私密快照。
- 最终轮之前，唯一最高正数报价达到第二名的 200% / 160% / 130% / 110%（依次按轮）即可提前成交。同价不提前成交。
- 最终轮最高正数报价成交；同价按主机收到有效报价的先后顺序，由最早提交者成交，不加拍。所有人报价为 0 则流拍。
- 有玩家成功成交时，10 秒揭示之后进入独立结算阶段，默认 60 秒，可在设置中调整为 10–180 秒。默认依次为逐件展示并累计价格 30 秒、基础总价加羁绊增值 6 秒、仓库价格 − 成交价 = 盈亏 9 秒、亏损分配 12 秒、结果停留 3 秒；修改时长后按比例缩放。右侧切换为结算面板，数字逐位垂直滚动并停在准确结果，仓库自动跟随当前物品滚动；成交结算结束后直接进入下一仓或最终排名。
- 揭示、逐件展示及盈亏滚轮期间保留原余额。盈亏演示结束后，赢家金币变化 = 含羁绊的仓库总值 − 成交价；如亏损，此时按其他在线参赛者的成交轮报价计算并固定全额奖励，分配演示结束后一次性入账，赢家不再额外扣款。0 报价无权重，其他人权重全为 0 或没有亏损时不分配。奖励按整数金币向下取整，余数按小数部分从大到小补齐，同余数按固定席位顺序分配，确保总额恰好等于亏损。动画只展示主机结果，不重复触发任何资金变动。
- 每人每轮可选择一种辅助操作，免费且立即生效：随机揭示 1 件物品完整信息、3 件轮廓、2 件品质或 4 件羁绊标签。优先随机选择尚未掌握对应信息的不同物品，剩余可探查数量不足时全部揭示。信息在本仓保留，下一仓清空；操作次数每轮重置。
- 完整信息显示实际物品图片，悬停或点击可看名称、基础价格、品质、尺寸和 tag。轮廓只显示占格；品质和标签仅显示位置标记及对应信息，不额外泄露名称、价格或图片。标签和品质详情可悬停查看。辅助操作类型在本轮结束后公开，其探查结果立即只发给本人，观战者不接收。
- 原有逐轮公共线索保留：件数、总占格、金及以上件数、最多标签的羁绊档位、品质分布。整仓物资、总值和羁绊实际增值在成交结算或流拍开仓后公开；流拍不触发成交结算，保留 15 秒开仓展示后自动继续。
- 出价或封盘期间断线者的未揭示报价归零，不参与获胜和亏损分配；揭示后已确定的成交结果保留，亏损奖励仍只分配给结算时在线者。后续仓库保持退出，多人局在线人数不足两人取消。单人局不提前成交，保留配置的全部轮数，最终金币照常结算；没有 AI 对手。全部仓库结束后按最终金币排名。

API 4 / manifest 2，普通 standard 排名协议。由原版小游戏轮换大游戏选择本包即可测试。协议、大游戏和所有已选小游戏的有效人数取交集；星潮团队模式会收窄为偶数。房间规则使用本包 config_schema；高级设置创建的预设仍走框架草稿/应用/保存流程。局内没有重开或单独暂停，切出窗口不会暂停计时。原型保留在 tmp，此包不依赖原型目录。

当前定向检查位于主项目 `tmp/test/auction_solo/new_rules.gd`、`new_view.gd` 和 `network.gd`，覆盖规则与隐私边界、1920×1080 三栏显示及滚动、真实双进程的两仓报价/探查/结算。测试不随包发布；真人多人手感、跨机器及外网尚未验收。旧技能和加拍检查不再作为当前规则的验收入口。

## 物资与同仓羁绊

`item_catalog.gd` 是静态物资 Resource，含 100 种物资、7 档品质、10 个 tag；当前配图位于 `assets/items/realistic/`，均为内置 imagegen 生成的写实透明 PNG，无投影，生成提示词和处理说明见该目录 `generation_prompts.json`。旧 SVG 保留但不再用于游戏显示。每种物资的基础价值、品质和宽高固定，开仓后点击查看详情，局内不再提供图鉴入口。完整图片审阅表：`doc/auction_inventory.html`（项目根目录），支持品质、尺寸筛选和价值排序。

品质由低到高：普通（白/灰）、优良（绿）、稀有（蓝）、珍贵（紫）、典藏（金）、传世（红）、至臻（彩）。彩色品质在仓库边框和图鉴中使用多色条。55 件占格不超过 2 格，12 件占格至少 20 格；最大物品为 10×6 古董跑车，另有 8×7 三角钢琴和 3×8 落地钟。窄格优先显示图标，悬停和详情栏显示名称、品质、价值与 tag。

高密度珍品的溢价已包含在基础价值中，不会在结算额外乘算。彩色小件：量子加密芯片 1×1 / 40,000，绝密数据核心 1×2 / 48,000，绯色永恒 1×1 / 52,000，深海之瞳 1×1 / 56,000；均高于彩色大型物品的 30,000–36,000。红色宝石、怀表、数据磁带等也有小体积溢价。

羁绊按单个拍卖仓库统计：同 tag 3 件 +15%，5 件 +30%，取最高档；不同 tag 相加，单件封顶 +60%。同款按实物件数计数，同件重复 tag 不重复计数。仅对应 tag 的物资增值，逐件向下取整；各仓独立，不跨仓累计。总值 = 基础价值 + 羁绊增值。成交赢家金币变化仍为总值减成交价，流拍不发放价值。

每仓按配置范围均匀抽取物品件数，先按七档品质权重选品质，再在该品质的目录条目中等概率选物品。默认相对权重为 120、90、60、40、20、6、2；允许同款重复出现。取消旧总值上限、主题重抽和固定组合回退，以免改变配置概率。主机和渲染共用大件优先的 16 列装箱算法，基础网格 16×16，每格 60 像素，纵向随物资增长，物品不旋转；仓库滚轮可浏览底部物品。开仓动画由主机时钟驱动。

旧物资回归已归档至主项目 `tmp/test/archive/`，不作为当前验收入口。

新增 20 件低价日常物资：白色普通 8 件、绿色优良 8 件、蓝色稀有 4 件，基础价值 30–600 金币，其中 18 件占 1–2 格。包括旧抹布、洗衣皂、钉子盒、胶带、手套、挂锁、卷尺、充电头、键盘、计算器、口琴、存储卡、温度计、电子秤和电烙铁等，沿用已有 tag 羁绊。这些物品参与当前可配置的品质抽样。

## 收纳尺寸

占格按现实相对体积与收纳状态分档：魔方、首饰等小件为 1×1，手持工具用窄长格，乐器与家具逐级增大。项链、手套等按收拢状态，帐篷、鱼竿、观测镜按折叠或收起状态；插图可展示展开外观。格子为抽象收纳单位，不对应固定厘米。

本次统一复核 100 件物资，调整 46 件占格；单件基础价值和品质不变，单格价格由当前宽×高即时计算。魔方、罗盘、腕表、怀表、玉佩、口琴和玩具小汽车为 1×1；相机、望远镜为 2×1；吉他 2×6、背包 3×4、鱼竿 1×5；三角钢琴 8×7、冰箱 4×7、古董跑车 10×6。
