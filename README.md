# 秘仓竞拍

2–8 人真人密封竞拍；每仓 5 轮，仅最终轮成交，结算按最终金币排名。

默认 3 仓、每轮 15 秒、初始 10000 金币。每仓一次私密鉴定；公开报价轮结束后揭示，仓库物品只在成交阶段显示。同价按轮换的公开优先顺序。所有人提交后提前结束竞价，缺席报价为 0。主机使用不广播的随机源；结果阶段自动推进。断线者退出，竞价未结算的报价归零；不足两人取消。

API 4 / manifest 2，普通 standard 排名协议。由原版小游戏轮换大游戏选择本包即可测试。协议、大游戏和所有已选小游戏的有效人数取交集；星潮团队模式会收窄为偶数。房间规则使用本包 config_schema；高级设置创建的预设仍走框架草稿/应用/保存流程。局内没有重开或单独暂停，切出窗口不会暂停计时。原型保留在 tmp，此包不依赖原型目录。

自动化：tests/original_arcade_rules_test.gd（规则、清单、人数）和 tests/original_arcade_network_test.gd（正式大厅、轮换、4/5 个 ENet 端、UI 回调和结算）。真实键鼠、多窗口手感及外网仍需人工检查。

## 物资与同仓羁绊

`item_catalog.gd` 是静态物资 Resource，含 100 种物资、7 档品质、10 个 tag；当前配图位于 `assets/items/realistic/`，均为内置 imagegen 生成的写实透明 PNG，无投影，生成提示词和处理说明见该目录 `generation_prompts.json`。旧 SVG 保留但不再用于游戏显示。每种物资的基础价值、品质和宽高固定，开仓后点击查看详情，随时可打开“物资图鉴 / 羁绊规则”。完整图片审阅表：`doc/auction_inventory.html`（项目根目录），支持品质、尺寸筛选和价值排序。

品质由低到高：普通（白/灰）、优良（绿）、稀有（蓝）、珍贵（紫）、典藏（金）、传世（红）、至臻（彩）。彩色品质在仓库边框和图鉴中使用多色条。55 件占格不超过 2 格，12 件占格至少 20 格；最大物品为 10×6 古董跑车，另有 8×7 三角钢琴和 3×8 落地钟。窄格优先显示图标，悬停和详情栏显示名称、品质、价值与 tag。

高密度珍品的溢价已包含在基础价值中，不会在结算额外乘算。彩色小件：量子加密芯片 1×1 / 40,000，绝密数据核心 1×2 / 48,000，绯色永恒 1×1 / 52,000，深海之瞳 1×1 / 56,000；均高于彩色大型物品的 30,000–36,000。红色宝石、怀表、数据磁带等也有小体积溢价。

羁绊按单个拍卖仓库统计：同 tag 3 件 +15%，5 件 +30%，取最高档；不同 tag 相加，单件封顶 +60%。同款按实物件数计数，同件重复 tag 不重复计数。仅对应 tag 的物资增值，逐件向下取整；各仓独立，不跨仓累计。总值 = 基础价值 + 羁绊增值。成交赢家金币变化仍为总值减成交价，流拍不发放价值。

每仓生成 6–9 件，以主题倾向抽样提高羁绊出现机会；单件品质相对权重依次为 120、90、60、40、20、6、2。含羁绊总值限制为 2,000–120,000；主机和渲染共用大件优先的 12×14 格装箱算法，放不下的组合重新抽取，物品不旋转。最多尝试 128 次后使用有效固定组合，因此实际概率也受同品质物品数量、主题、价值和空间约束。所有物资都可抽到。公开/私密鉴定均针对含羁绊的总值；只有开仓快照才包含物资、tag 数量及增值。开仓展示 15 秒，逐件发现动画由主机计时驱动。

新增回归：`tests/auction_inventory_test.gd` 覆盖阈值、重叠 tag、取整、生成边界、占格、私密信息、跨仓清理与结算幂等；现有 ENet 测试的 `--case=auction_master` 检查正式大厅中的传输和结算。

新增 20 件低价日常物资：白色普通 8 件、绿色优良 8 件、蓝色稀有 4 件，基础价值 30–600 金币，其中 18 件占 1–2 格。包括旧抹布、洗衣皂、钉子盒、胶带、手套、挂锁、卷尺、充电头、键盘、计算器、口琴、存储卡、温度计、电子秤和电烙铁等，沿用已有 tag 羁绊。仓库总值范围与品质权重保持不变。

## 收纳尺寸

占格按现实相对体积与收纳状态分档：魔方、首饰等小件为 1×1，手持工具用窄长格，乐器与家具逐级增大。项链、手套等按收拢状态，帐篷、鱼竿、观测镜按折叠或收起状态；插图可展示展开外观。格子为抽象收纳单位，不对应固定厘米。

本次统一复核 100 件物资，调整 46 件占格；单件基础价值和品质不变，单格价格由当前宽×高即时计算。魔方、罗盘、腕表、怀表、玉佩、口琴和玩具小汽车为 1×1；相机、望远镜为 2×1；吉他 2×6、背包 3×4、鱼竿 1×5；三角钢琴 8×7、冰箱 4×7、古董跑车 10×6。
